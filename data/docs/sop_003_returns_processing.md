# SOP-003: Returns Processing
Version: 2.0 | Last Updated: 2026-02-01

## Purpose
Process customer returns efficiently and accurately within 48 hours of receipt.

## Procedure
1. **Receive**: Log return receipt in Returns System
2. **Inspect**: Within 48 hours of receipt at warehouse
3. **Grade**:
   - Grade A: Like-new condition -> restock at 90% value
   - Grade B: Used but functional -> discount channel at 60% value
   - Grade C: Damaged beyond use -> dispose/recycle
4. **Update**: Record return reason code in system
5. **Refund**: Process within 3 business days of receipt

## Quality Triggers
- Any category return rate > 12% -> Flag for quality review
- Return rate above category average for 3+ consecutive weeks -> Supplier review
- Single SKU return rate > 20% -> Immediate quality hold and investigation
