# SLA Targets

| Metric | Target | Critical Threshold |
|---|---|---|
| Avg Fulfillment Time | <= 24 hours | > 36 hours |
| Fulfillment Time p95 | <= 48 hours | > 60 hours |
| Return Rate | <= 8% | > 12% |
| CSAT Score | >= 4.2 / 5.0 | < 3.8 |
| Avg Wait Time | <= 2 minutes | > 4 minutes |
| Inventory Accuracy | >= 98% | < 95% |
| On-Time Delivery | >= 95% | < 90% |
| Cart Abandonment | <= 70% | > 80% |

## Escalation Protocol
When a KPI breaches its critical threshold for 2 consecutive days, a Tier-2 escalation is triggered. For 3+ consecutive days, a Tier-3 escalation with COO notification is required.
