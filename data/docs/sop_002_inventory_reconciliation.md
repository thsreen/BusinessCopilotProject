# SOP-002: Inventory Reconciliation
Version: 1.3 | Last Updated: 2026-01-15

## Purpose
Maintain inventory accuracy >= 98% across all warehouses.

## Weekly Cycle Count Procedure
1. **Select SKUs**: 5% of SKUs per category (random stratified sampling)
2. **Count**: Physical count by warehouse team
3. **Compare**: Against WMS book quantity
4. **If variance <= 2%**: No action needed
5. **If variance 2-5%**: Recount immediately; if confirmed, adjust WMS
6. **If variance > 5%**: Full category recount + Tier-1 escalation

## Responsibilities
- Warehouse Lead: Schedule and supervise counts
- Inventory Analyst: Update WMS with adjustments
- QA: Audit count accuracy quarterly

## Compliance
- Missed cycle count requires written explanation to Director of Fulfillment
- Two consecutive misses trigger an automatic escalation
