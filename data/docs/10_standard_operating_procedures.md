# Standard Operating Procedures

## SOP-001: Fulfillment Delay Handling
When fulfillment time exceeds 30 hours average for a day:
1. Identify bottleneck (picking, packing, carrier pickup)
2. Alert Warehouse Lead
3. If > 36 hours -> trigger Tier-1 escalation
4. Communicate updated ETA to affected customers
5. Log root cause in incident tracker

## SOP-002: Inventory Reconciliation
Weekly cycle count process:
1. Count 5% of SKUs in each category
2. If variance > 2% -> recount immediately
3. If variance > 5% -> full category recount + Tier-1 escalation
4. Update WMS with corrected counts
5. File reconciliation report by Friday COB

## SOP-003: Returns Processing
1. Inspect returned items within 48 hours of receipt
2. Grade items (A: Like-new -> restock, B: Used -> discount, C: Damaged -> dispose)
3. Update return reason codes in system
4. If category return rate > 12% -> flag for quality review
5. Process refund within 3 business days

## SOP-004: Monthly Ops Reporting
1. Compile daily KPIs into monthly summary by 3rd business day
2. Compare actuals vs targets with variance analysis
3. Identify top 3 issues and propose corrective actions
4. Draft narrative report with trends and recommendations
5. Submit to VP Operations by 5th business day
