# Incident Report: Defective Headphone Batch

## Incident ID: INC-2026-002
- Date Detected: March 22, 2026
- Severity: High
- Reported By: Lisa Park (VP Customer Experience)

## Timeline
- Mar 20 -- Return rate for Electronics begins unusual increase
- Mar 21 -- 350 headphone returns received in single day (normal: ~40/day)
- Mar 22 -- Quality team investigates; identifies batch number HP-2026-001
- Mar 23 -- Supplier contacted; batch confirmed from single production run
- Mar 24 -- Recall initiated; all customers who received units from affected batch notified
- Mar 28 -- 2,200 of 3,000 affected units returned
- Apr 7 -- Recall complete (2,850 returned, 150 lost/in-transit)

## Impact
- Return rate for Electronics: 14.2% (peak week Mar 22-28)
- 3,000 units affected
- Estimated revenue impact: $180,000 (refunds + shipping)
- CSAT impact: -0.3 on Electronics category

## Root Cause
Supplier QA failure -- inadequate testing on production run. Sound distortion in left channel above 70% volume.

## Action Items
1. [Done] Supplier recall with full refund
2. [Done] New incoming inspection SOP for audio products
3. [In Progress] Diversify headphone supplier base (currently 100% single source)
4. [Done] Alert customers proactively (not reactive)
